## 🔬 How I Build

```python
class Engineer:

    def solve(self, problem):
        understand(problem)
        architecture = design(problem)
        solution = build(architecture)

        while not production_ready(solution):
            test(solution)
            debug(solution)
            optimize(solution)

        automate(solution)
        deploy(solution)

        return "continuous improvement"
```
