## ⭐ Flagship Project

### AnimeVault - Premium Anime Streaming Platform

More than just another anime site, AnimeVault is grounded in the **world of anime production** rather than genre tropes. This project demonstrates my ability to craft meaningful user experiences by drawing inspiration from actual anime creation materials: animation cels, storyboard paper, screen tones, and production notes.

#### Engineering Highlights
- **Design System**: Created a cohesive visual language from anime production artifacts (Ink Black, Storyboard Cream, Cel Violet, etc.)
- **Interactive Lore Depth Meter**: Built a radial visualization using SVG/CSS that measures engagement depth across six axes (Art Process, Story Development, Sound Design, Voice Acting, Cultural Impact, Fan Theories)
- **Performance Conscious**: Efficient CSS selectors, JS event delegation, and asset placeholders for future optimization
- **Accessibility First**: Semantic HTML with ARIA labels, visible keyboard focus, reduced motion support, and WCAG AA color contrast
- **Exploration-Driven Layout**: Asymmetrical production-board layout that matches how fans actually explore (video → art → lore → comments)

This project showcases my UI/UX expertise, attention to detail, and ability to translate domain-specific knowledge into engaging digital experiences — skills directly transferable to DevOps tooling and internal developer platforms.
